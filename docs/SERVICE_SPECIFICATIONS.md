## 7. Calculator Inputs (machine-readable)
Service keys: `web`, `app`, `content`, `ebook`. Tier keys: `starter`, `growth`, `premium`.

| Service | Tier | Base price | Included units | Unit | Extra unit price |
|---------|------|-----------:|---------------:|------|-----------------:|
| web | starter | 1500 | 5 | page | 120 |
| web | growth | 3500 | 12 | page | 150 |
| web | premium | 9000 | 25 | page | 200 |
| app | starter | 6000 | 8 | screen | 250 |
| app | growth | 12000 | 20 | screen | 300 |
| app | premium | 30000 | 40 | screen | 400 |
| content | starter | 50 | 0 | word | 0.08 |
| content | growth | 150 | 0 | word | 0.12 |
| content | premium | 400 | 0 | word | 0.20 |
| ebook | starter | 300 | 0 | ebook page | 5 |
| ebook | growth | 900 | 0 | ebook page | 12 |
| ebook | premium | 2500 | 0 | ebook page | 35 |

Rules:
1. `unitsCharged = max(0, quantity - includedUnits)`; line = `base + unitsCharged * extraUnitPrice`.
2. **App platform multiplier:** Android only = 1.0, iOS only = 1.0, Both = 1.5 (applied to the app line).
3. One-time add-ons are added to the subtotal; monthly add-ons are listed separately.
4. Rush: subtotal x 1.35 when enabled.
5. Estimate range: `low = round(total x 0.90)`, `high = round(total x 1.20)`, rounded to nearest $10. The "starting at" label uses `low`.
6. Default quantities: web 5 pages, app 8 screens, content 1000 words, ebook 100 pages. Min quantity 1; max web 100, app 100, content 100000, ebook 600.
